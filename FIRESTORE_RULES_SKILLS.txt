===============================================
FIRESTORE RULES FOR SKILLS & HOBBIES FEATURE
===============================================

Add these rules to your Firebase Console:
Firebase Console → Firestore Database → Rules tab

Paste this inside the "match /databases/{database}/documents {" block:

    // Skills & Hobbies - skill_path collection
    match /skill_path/{document} {
      allow create: if request.auth != null &&
                      request.resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
      allow read: if request.auth != null &&
                     resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
      allow write: if request.auth != null &&
                      resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
      allow delete: if request.auth != null &&
                       resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
    }

EXPLANATION:
- Users can only create skill paths where user_ref points to their own user document
- Users can only read/write/delete their own skill paths
- This prevents users from seeing or modifying other users' skill paths

FULL EXAMPLE:
Your complete Firestore rules should look something like this:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Users collection
    match /users/{document} {
      allow create: if request.auth != null;
      allow read: if request.auth != null;
      allow write: if request.auth != null && request.auth.uid == document;
      allow delete: if false;
    }

    // Skills & Hobbies - skill_path collection
    match /skill_path/{document} {
      allow create: if request.auth != null &&
                      request.resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
      allow read: if request.auth != null &&
                     resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
      allow write: if request.auth != null &&
                      resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
      allow delete: if request.auth != null &&
                       resource.data.user_ref == /databases/$(database)/documents/users/$(request.auth.uid);
    }

    // ... your other collection rules ...
  }
}

STEPS TO ADD:
1. Go to https://console.firebase.google.com/
2. Select project: parenting-plus-7szrif
3. Click "Firestore Database" in left menu
4. Click "Rules" tab at the top
5. Add the skill_path match block
6. Click "Publish" button

After publishing, the Skills & Hobbies feature should work without permission errors!
