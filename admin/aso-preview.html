A — Benefit + UI

Safest. Shows what the app does immediately. Best when the meal-planner UI is genuinely the headline feature.

Best starting bet

B — POV-led

Differentiates more. Reads as positioning, not features. May convert better with mom-niche audience but riskier on cold traffic.

Strong A/B challenger

C — Lifestyle hero

Headspace / Calm pattern. Real photo of a mom + caption, NO UI shown. Highest emotional pull, lowest "what is this" clarity.

Test late, not first

D — Illustrated hero

Brand-distinctive, scalable, no photoshoot needed. Pairs with the gradient palette. Won the original Headspace battle.

High-leverage if executed well
